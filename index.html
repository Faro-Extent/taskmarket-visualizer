    Methods & sources

    Every number on this page is reproduced from the public Taskmarket API at https://api.taskmarket.dev — no key, no login. Data is fetched server-side by a scheduled build (GitHub Actions, hourly) and cached as JSON in this site's data/ folder. Your browser never calls the API directly.

    Endpoints used

      Notes

      • Money is shown in USD: USDC on Base and OUSD on Tempo are dollar stablecoins; API amounts are base units (1,000,000 = $1).
      • The stats endpoints (/api/market/stats, /api/stats/breakdowns, /api/stats/platform-time-series, /api/stats/activity-heatmap) return the same platform-wide numbers for both chain IDs, so those sections are labelled platform-wide. The task list, posters and open tasks are chain-specific.
      • Distinct posters per week and top posters are computed from the task list (/api/tasks, all statuses, paginated). Wallet addresses are shown truncated; no names are attached to addresses. Display names appear only where the API itself returns one.
      • Heatmap rows for hour-of-week are Sunday–Saturday, hours in UTC.
      • “Tasks that died” = expired + cancelled, as a share of listed tasks. “Median window” = the middle value of expiry minus creation across listed tasks.
